## Concept

A 30-second promo for a fictional SaaS productivity tool — demonstrates how the Promo template handles quick cuts, big visual hooks, and a strong call-to-action.

**Fictional product name:** **FlowDesk** — collaborative workspace for distributed teams.

> All branding in this sample is **neutral placeholders**. The product name "FlowDesk" and the visuals are fictional; users can swap them via the form's brand-color, accent-color, and font fields.
